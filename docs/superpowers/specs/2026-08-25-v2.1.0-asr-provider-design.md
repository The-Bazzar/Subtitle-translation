# 2.1 发布范围与后续 ASR 路线图

当前实现以 [架构与发布范围](../../v2.1-architecture.md) 和 [AGENTS.md](../../../AGENTS.md) 为准。
文件名保留历史链接；多 ASR 兼容层不再属于 2.1.0 的交付范围。

## 2.1 已实现范围

- 单一 WhisperX 入口，原始 JSON 和 batch generation/恢复协议不变。
- translate 同回合整句翻译及成对源/目标语义分段，移除独立 split。
- 可选翻译后窗口 corpus MFA，合并跨段来源，一次 align/批量导出。
- glossary/source_review 是唯一源文编辑入口；仅在 MFA 路径采用修订稿。
- 纯译文 proofreading 保留可选，模板默认关闭，不修改源文或时间。
- 场景检测只写 sidecar，移除时间吸附、美化和显示留白。
- CLI 仅保留项目参数及 only 模式，开关/调优统一 .env，help 显示全部子命令帮助。
- 清除旧 split、源文校对、前置全文/单窗口 MFA 与 partial 解析代码，测试迁移到现行协议。

## 发布验收

自动回归覆盖源文只读、实际译文非空、整句 fallback、词映射、窗口合并、
缓存隔离、取消传播、资源调度和原子导出；外部模型和工具均 mock。
wheel/sdist 应含完整模块与示例，不含本地配置、媒体或模型，脱离源码验证 help/init。

真实长音频、多口音/OOV、阅读速度、人工重切量、校对收益和 Linux 原生安装矩阵仍需独立验收。
安装成功、词时间结构合法或短样本可运行不等于听录与翻译质量已证明。

## 后续版本

1. 在不改变当前 generation/取消/资源协议的前提下，引入共享 adapter/worker 和不可变候选结果。
2. setup 允许选择单一或多个已支持引擎；WhisperX、Parakeet、Qwen 等地位平等，未选依赖不 eager import。
3. ASR 只识别；多源文本优选仍在 glossary，与术语/上下文合并处理，必须有实际文本 fallback。
4. 单引擎同样可用，不要求原生词轴；明确范围的粗时间供后置 MFA 使用。
5. 固定版本真实 fixture、安装、推理、平台与性能验收完成后，才声明对应 Provider 已兼容。
6. 多语言通过独立 backend/profile 扩展，不能把默认翻译语言入口等同于 MFA 已支持该语言。
