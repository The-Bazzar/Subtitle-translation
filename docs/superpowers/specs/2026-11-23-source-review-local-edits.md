# Source review 局部编辑约束

采用稿是保留说话者表达的工作稿，不是对原文进行改写。提示词明确保留句式、词序和分句顺序；尴尬但可理解的说法如果必须重组才能变顺，就原样保留。完整术语库、现有响应字段与 ASR/MFA 职责边界不变。

英文编辑由本地词级差异作第二道检查。标点、大小写及弯直撇号的差异不计入词改；每个差异块按增删两侧的较大词数计入预算，readability 总计至多 2，context 至多 4。若差异在删除和插入区域同时出现同一词，则保守视为移动而拒绝。此规则可能拒绝某些局部改动，不是语法解析器，也不证明语义一致；其他语言保留提示词约束，不套用英文词预算。

非法项走现有一次逐项重试；再次失败保留原始候选、来源和粗时间。采用稿发布和读取同样校验。text-adoption-v2-local-edits 使旧策略检查点不再命中，历史快照和原始 ASR 不改写。翻译及 MFA 仍只根据实际采用稿及各自契约重建。涉及 D3/D7 文本契约和身份，发布前需实现 PR 评审。
