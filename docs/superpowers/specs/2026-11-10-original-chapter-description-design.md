# 原片章节提取与简介翻译

状态：v2.0.2 元数据功能扩展，不改变现有字幕处理顺序或设计不变量。

## 数据来源与输出

仅检查字幕项目目录内同名 `<base>.original.mkv`。通过 ffprobe `-show_chapters -of json` 读取容器元数据，不推断未提供的章节，也不读取编辑版或其他项目原片。ffprobe 复用现有工具定位规则，优先采用已配置 ffmpeg 同目录工具；参数使用数组传递，支持含空格路径，探测限时 30 秒。

从每章 start_time 与 title 标签生成按时间稳定排序的章节列表。无效/非有限/负时间忽略，空标题使用中性 Chapter N，原片同一时间的多个章节保留。开始时间在本地保留，展示向下取整至秒并格式化为 HH:MM:SS，不改变实际章节或字幕时间轴。

## 翻译契约

扩展已有元数据对象协议，在标题、简介和标签之外携带 chapters 数组。每章有稳定数字 id、start_time 和原始 title；响应的 chapters 只需 id/title，时间不从响应读取。所有内容在同一次元数据请求翻译，不新增字幕 LLM stage，完整 glossary 继续常驻，章节标题也可参与当前项目的检索 query。

```json
{
  "title": "译后标题",
  "description": "译后简介",
  "tags": ["电影"],
  "chapters": [
    {"id": 1, "title": "开场"},
    {"id": 2, "title": "镜头选择"}
  ]
}
```

按原始 ID 恢复章节顺序并绑定本地开始时间，未知 ID 不输出，重复/缺失/空译名逐项回退原题。标题内换行折叠为空格，不能生成额外列表项。提示词要求已有简介中的重复章节列表放入专用字段，保留其他简介段落，不在本地用正则删除自然文本。

目标 description 保留已有标题、元数据头、简介和标签布局，在简介之后、标签之前追加“章节”区块及逐章时间码。目标语言文件后缀继续遵循既有语言配置，不硬编码只能输出中文。

## 降级与兼容

无原片不启动探测；无章节不输出空区块。提取失败只警告，仍翻译原有元数据。没有原简介文件但有同名原片时，也进入元数据翻译。整次简介请求失败仍保留旧目标简介，不因本功能覆盖已有输出。

本功能只扩展既有元数据读取/翻译，不改变 JSON 主字幕、原始媒体、ASR/词轴、glossary 缓存、SDK 重试策略或 batch 的锁/generation/原子发布规则；不修改正式 prompt example 文案。

## 验证

网络、LLM 和 ffprobe 均 mock。测试覆盖原片定位、含空格路径、配置工具定位、空/坏章节、无题章节、重复时间、小时级时间码、乱序/缺失/重复/非法响应、时间不被模型改写、原简介缺失、探测与翻译失败。修改 translate_srt 后运行全量 unittest，并验证 wheel/sdist 包含章节模块及正确版本且不含本地配置或未发布流程代码。

ffprobe 章节和 JSON 参数依据：[FFmpeg 官方文档源码](https://github.com/FFmpeg/FFmpeg/blob/master/doc/ffprobe.texi)。
