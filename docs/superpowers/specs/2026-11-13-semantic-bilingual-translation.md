# 翻译与双语语义断句同回合设计

状态：codex/v2.1.0 开发实现；替代此前“独立 LLM 源文断句 -> 固定事件翻译分配”的阶段/响应契约。默认路径和 MFA_ENABLED=1 均使用本协议，需 PR 评审。

## 当前流程

```text
MFA_ENABLED=0：WhisperX -> scene detection -> glossary -> translate（整句理解、翻译、双语语义断句）
      -> 本地词轴投影 -> 可选纯译文校对 -> ASS
MFA_ENABLED=1：WhisperX -> glossary/source_review -> translate（同时生成 en/zh 事件）
       -> 窗口 corpus MFA -> scene detection -> 可选纯译文校对 -> ASS
```

不再运行独立 split LLM call，不读 split_prompt 作为运行阶段，旧 split helper 已删除。pySBD 只组织完整翻译上下文，不替代字幕语义断句。场景检测只写 sidecar，不改时间。

## 一次请求与响应

每项输入完整源句、邻接上下文、完整 glossary 及当前项目检索证据。不预生成英文事件，不提供边界 ID、字符坐标、词时间、目标字符数或事件数量等数学任务。所有有效句段都进入翻译，不按 72 字符跳过分割判断。

LLM 在同一次响应中给出整句译文和语义对应的双语片段：

```json
{
  "items": [
    {
      "id": 1,
      "zh": "虽然价格很高，我还是买了。",
      "split_events": [
        {"en": "Although it was expensive,", "zh": "虽然价格很高"},
        {"en": "I bought it.", "zh": "我还是买了"}
      ]
    }
  ]
}
```

en/zh 使用实际源/目标语言 key。模型不输出事件 ID、source_range 或时间；整句 zh 是完整语义译文和整句回退来源，事件 zh 是用于展示的自然字幕，不要求拼接后逐字符等于整句 zh。不同空白、标点或自然措辞不触发回退。

## 提示词与必要保护

以完整句意、转折、解释、从句和完整思想组织字幕，避免多从句长段堆积或过碎的依附片段，保持名字、固定表达及玩梗连贯。中文按整句语义自然表达并分配，不机械逐词直译。不要求模型数字符、计算比例、求时间、引用边界 ID 或证明拼接等式；不规定分段数量。

源文在 glossary 后仍只读。模型复制顺序连续源文片段，本地容忍片段内/边界的空白表示差异，并从原稿恢复展示文字和位置；不能以断句为由修改事实、语法或标点。定位失败、源文缺失/重复、片段为空或结构无效但整句译文有效时，直接保留原句及本次整句译文作为单一事件，原因只写控制台日志。

句段 ID 仍需能关联输入，响应仍需合法 JSON，实际整句译文不能空；这些是传输/输出安全检查，不是语义数学约束。完全没有有效整句译文时沿用有界重试/失败，不输出空字幕。不得拼接不同响应中的半份产物。

## 本地定位与对轴

模型成功返回后，本地才生成稳定事件 ID 和 segment-local 字符范围。MFA 路径保持 pending 时间，在后置 MFA 中定位最终双语事件。默认路径只在完整原生词轴可映射时投影多个事件，否则保留整句粗时间和已有整句译文，不为保住分割均分时间。MFA 的有限时间、范围、词序、窗口归属和不可分离词映射检查仍保留；删除的是给 LLM 的数学任务，不是时间轴有效性保护。

SPLIT_ENABLED=0 时仍一次翻译，只保留一个完整双语事件。TRANSLATE_CONTEXT_WINDOW 控制翻译上下文范围。旧 --no-split、--split-max-chars、--split-max-duration、--split-context-window 均不再解析，开关/调优仅在 .env 设置。

## 校对、缓存和迁移

纯译文校对只改目标文本，事件 ID/源文/数量/时间只读；也不再要求目标片段严格拼回整句译文。不需要重新计算语义边界或回调上游。
模板 MFA_ENABLED=1 默认常开。proofread_target_events 接受后置 MFA 的精确时间事件、整句回退和粗时间合并结果；保留词轴及其状态、来源范围与时间元数据，整句/事件译文和 proofread_key 一起保存。PROOFREAD 默认仍为 0，与 MFA 独立控制。

联合协议版本 semantic-bilingual-events-v1 绑定源文/generation、上下文、glossary/检索、语言、模型/prompt 和 no-split 模式，同时生成事件规划与翻译身份。旧独立 split/固定事件结果不冒充新协议完成；首次切换需要一次性重译，失败句段继续按检查点恢复，不删除原始输入或旧文件。

MFA 原生 corpus 身份仍绑定窗口音频、定稿及声学依赖，不因本次语义协议升级直接失效。实际文字/窗口不变时可复用词轴，仅重新投影新事件。新默认/实验路径都移除独立 split 调用，不在内部偷偷补一个译文分割请求。

风格 prompt example 由既定外部仓库维护，本次不修改其文案。语义分割约束和响应格式由 bilingual_translation.py 中的代码级阶段协议追加，覆盖旧的独立 split/固定事件/数学拼接说明。

## 验证边界

translate 每次应用层对话请求打印递增轮次、尝试和句段 ID，返回后打印响应字符数/耗时及每句事件数、分段/整句/回退、待重试 ID。校验后在实际轮次下逐句段/event 打印编号、稳定 ID 和当前时间，尚未 MFA 时明确 pending；失败句段显示 retry/failed，无效响应不冒充有效事件。逐 event 始终完整输出采用的原文/译文，仅按 LOG_LEVEL 过滤，JSON 字符串转义控制字符以保持单行；正常 split/unsplit 为 INFO，回退/重试/失败等异常状态为 WARNING，任务级错误仍为 ERROR。项目名用于区分 batch；取消/错误仍只记录类型并传播。日志在 stderr 即时输出，不影响 stdout marker。缓存命中也逐 event 输出并注明 cache=hit，不伪造 LLM 轮次；SDK 内部 HTTP 重试耗时仍包含在本轮。日志不输出 prompt、glossary、检索上下文、未采用原始回复或密钥，不参与输入身份或修改字幕数据。

单元测试 mock 模型/工具，覆盖短句同回合分割、不等拼接的自然译文、原文定位/重复/空白、CJK 入口、非中文目标、非空保护、整句回退、no-split、默认词轴投影、无轴降级、取消及缓存迁移。真实 MFA 短样本使用语义 schema fixtures 验证后续对轴/缓存，不代表真实 LLM 的断句、翻译质量已通过。

本变更涉及 D2/D3/D6/D7 阶段顺序、缓存、模型协议与职责。batch generation、资源池、MFA corpus 批量执行、安装和原子发布规则不变，多引擎继续暂缓。
