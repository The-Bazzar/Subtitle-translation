# 2.1 架构与发布范围

本文描述当前代码，不是历史目标方案。运行规则以 [AGENTS.md](../AGENTS.md) 为准，
用户命令/变量见 [CLI 配置表](cli-and-env.md)。包版本和标签只在正式发布步骤统一调整。

## 范围

单一 WhisperX、联合双语语义翻译、可选窗口 corpus MFA、只读场景检测、纯译文校对、ASS/硬压。
不在本版接入 Parakeet/Qwen、多源勘误、自动 ASR 路由或多语言 MFA profile。
默认路径保留既有多语言输出入口；MFA 当前仅验证英文源文。

## 阶段

MFA_ENABLED=0 兼容路径：download -> prepare-video -> WhisperX -> scene detection -> glossary
-> bilingual translate -> ASR timing projection -> optional target proofread -> ASS -> optional burn。

模板默认 MFA_ENABLED=1：WhisperX -> glossary/source_review -> bilingual translate -> window corpus MFA
-> scene detection -> optional target proofread -> ASS -> optional burn。

glossary 是唯一自动源文编辑阶段。pySBD 只从完整采用稿组织上下文，字幕事件由翻译模型在同一回合生成。
完整 glossary 常驻，检索只补充；模型不判断音频真实性，不生成词时间或字符坐标。
本地复制并定位连续源文片段，生成事件 ID/范围，不以目标译文的严格拼接等式拒收结果。
无有效片段但整句译文存在时保留整句；没有实际译文则有界重试/失败。

## 声学与时间

使用来源 ASR 粗时间定位音频，跨段或共享来源的连续上下文合并成处理块。
当前上限 60 秒/12 源单元、零额外 padding。超限范围保留内容并降级，不扩成无锚点全文。
每块分别保存 16 kHz mono PCM WAV 与定稿，全部有效块加入同一项目 corpus，固定 num_jobs=1。
一次 align 共用模型/自适应，一次 exporter 按稳定窗口 ID 读取词 tier，不把 phone 或文件顺序当词源。

必要词、有限/有序时间、窗口范围、异常词长/空洞和不可分离映射仍本地验证。
局部时间加准确 sample 偏移一次；不缩放词轴，不补造缺失词，不以结构合法证明声学正确。
失败句段保留整句双语内容与来源粗时间。若与相邻输出重叠且含 coarse，则协调成完整双语粗时间输出，
保留全部源文范围/译文/来源，不回调模型，不改文本检查点。

场景检测只生成 .scenes.json/.scenechange.txt，不吸附、偏移、补时长/间隔或改事件。
工作 .beautified.json 沿用名称，但派生词轴只在 segments[].words[]，不复制旧根级 word_segments。

## 缓存与取消

- 原始识别/媒体 generation 由现有 scheduler/cache/worker 拥有。
- source_review 与 glossary 快照绑定，非空术语文件不单独代表审阅完成。
- 文本检查点保存完整或部分成功的联合译文；pending 事件没有精确时间，不能导出。
- MFA 身份绑定完整有序 corpus、音频/定稿、模型/环境/profile/解析器，共享自适应不混用单块旧结果。
- 定时投影绑定有效事件和后处理策略；修改场景参数只刷新独立 sidecar。
- 校对只更新目标，缓存绑定现有事件/译文与模型/prompt，不修改源文、数量、ID 或时间。

缓存均需匹配实际输入及完整结果。旧 helper/解析器清理可能令旧声学缓存 miss；旧文件不删除，
不因此重跑输入不变的语义请求。取消优先于 fallback，所有新请求、工具与发布遵守 admission。
临时文件原子替换不替代 batch 外层的输入快照/锁/candidate 检查。

## 发布验证

自动测试只 mock 网络/LLM/ASR/MFA/ffmpeg，覆盖当前阶段协议、原样词映射、缓存失效、部分恢复、
取消、资源调度和导出。退役算法的专用测试删除，有效基础覆盖迁入当前测试模块。
打包需检查 wheel/sdist 模块和示例完整、不含本地配置或媒体，并验证脱离源码目录运行的 help/init。
MANIFEST.in 显式包含测试辅助模块、脚本和文档，使源码包可以独立运行回归。
字幕时间序列化按总毫秒/厘秒取整后分解，避免小数进位生成非法 ASS；不改内部时间轴。
Windows 需要 PowerShell 7；MFA 默认原生 x86_64，显式 --distribution 保留 WSL。
见 [Windows 安装设计](superpowers/specs/2026-11-13-native-windows-mfa-setup.md)。
原生 Windows/Linux 的完整安装、长音频及声学质量仍需独立验收。
