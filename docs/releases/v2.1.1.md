# v2.1.1：调用兼容修复与独立译文校对

## 主要变化

- 翻译与校对恢复 2.0.2 的项目内共享会话、批量 RAG、温度和三次尝试/3、6 秒退避；保留 2.1 的同回合双语语义断句与纯译文校对结构。
- 修复 MFA 路径 glossary 遗漏检索器、全项目预检索改变调用顺序，以及目标回复标签/语言键兼容处理缺失。
- 显式 translate 每次重新翻译和联合断句，启用时重新校对，不以旧工作 JSON 或文本/定时投影跳过语义请求；pipeline/batch 内部续跑规则不变。
- 新增独立 proofread 命令，读取已有完整定时翻译工作 JSON，只校对目标文本；支持原位更新或 --output-json 另存，不重跑翻译、MFA、术语生成、场景或元数据翻译。
- 保留工作 JSON 的源文、事件身份、词轴、时间精度和扩展字段，增加语言对记录；校对输出暂存后发布，检测 JSON 竞争修改并在运行期发布失败时尽力回滚。
- 源文 ASS 统一为 .<source>.ass，不再以 proofread 后缀暗示可选校对已执行。

## 升级注意

```text
subtitle-translation translate video.json
subtitle-translation proofread video.beautified.json
subtitle-translation proofread video.beautified.json --output-json reviewed.beautified.json
```

- translate 现在每次都会重新请求翻译，运行前需考虑模型费用。术语/采用稿、ASR、场景、检索库及原生 MFA 声学缓存保留，不需要删除项目文件或启用 FORCE_REBUILD。
- proofread 默认原位更新工作 JSON 并重新导出规范 ASS/SRT；保留上次结果时使用 --output-json。--output 仅指定双语 ASS。原始 ASR、ASS/SRT、旧扁平结构及 pending 文本检查点不作为校对输入。
- 显式 proofread 不受 PROOFREAD=0 影响。该开关只控制翻译流程内的可选校对，模板默认仍为 0；MFA_ENABLED 默认和既有配置不变。
- 新工作 JSON 保存 subtitle_languages；独立校对优先使用已保存语言，参数冲突报错。旧完整工作文件缺失语言对时警告，可用 --lang/--target-lang 明确指定。
- .en.proofread.ass 改为 .en.ass；旧文件不自动删除或迁移，播放器/脚本需使用新路径。
- 移除 TRANSLATE_CONTEXT_WINDOW。完整 glossary 和 Provider request_kwargs 规则不变，外部维护的 prompt example 不修改。
