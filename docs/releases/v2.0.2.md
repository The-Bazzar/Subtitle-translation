# v2.0.2

新增原片内嵌章节提取与目标语言简介翻译。

## 更新内容

- 从同名 `<base>.original.mkv` 读取章节标题和开始时间，翻译后追加到 `.zh.description` 等目标语言简介。
- 章节标题与视频标题、简介及标签使用同一次翻译请求，遵循现有术语库和项目上下文。
- 本地保留原片时间，按时间顺序输出 `HH:MM:SS 标题`；模型不能改动时间或新增章节。
- 没有原简介文件时也可输出章节简介；章节译文缺项/无效时逐项保留原标题，探测失败不阻塞其他元数据翻译。
- 包含已合入的 embedding 单文本请求兼容修复，旧 `EMBEDDING_BATCH_SIZE` 不再生效。

## 升级须知

无需新增环境变量或重新执行 ASR。保留项目内的原片并重新运行现有 translate/pipeline 命令，可刷新目标语言简介。ffprobe 优先使用已配置 ffmpeg 同目录的工具，章节探测最多等待 30 秒。

现有字幕处理顺序、时间轴、batch 资源与恢复协议不变。

详细迁移与降级规则见 [MIGRATION.md](../../MIGRATION.md)。
