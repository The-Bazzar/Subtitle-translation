# v2.0.0

字幕流水线升级为可安装的 Python CLI，统一单任务、批处理和独立工具入口，并引入按阶段调度的批处理资源管理。

## 主要变化

- 新增统一命令 `subtitle-translation`，支持 `pipeline`、`batch`、`translate`、`merge-ass`、`download`、`prepare-video`、`whisper`、`burn` 和 `init`。
- Python 直接编排各阶段；核心实现集中到 `core/`，PowerShell/bash 安装及兼容入口移到 `scripts/`。
- 下载与编辑视频重编码拆为独立阶段，保留原片用于硬字幕渲染。
- batch 自动计算 CPU/IO 并发，prepare/burn 共用最多 4 路 NVENC，WhisperX 与 NVENC 互斥；单个常驻 worker 串行识别并复用模型。
- 增强任务失败处理、两级 Ctrl+C 中断、generation/cache 恢复协调，以及文本和 JSON 批处理报告。
- setup 安装指向项目虚拟环境的全局 CLI shim；配置示例统一随 Python package 分发，升级只补充缺失配置。
- 修复输出目录与配置目录混用、batch/pipeline 跳过阶段行为不一致，以及 embedding 未读取 provider 默认模型的问题。

## 升级须知

1. Windows 使用 PowerShell 7，运行 `./scripts/setup.ps1`；Linux/WSL 运行 `./scripts/setup.sh`。setup 会清空并重建项目 `.venv`，保留已有本地配置。
2. 旧脚本路径需要添加 `scripts/`，推荐改用 `subtitle-translation pipeline URL` 或 `subtitle-translation batch URL1 URL2`。
3. batch 不再接受 `--jobs`、`--io-jobs`、`-j` 或 `MaxJobs`。并发容量自动确定。
4. pipeline/batch 仅提供 `--skip-burn`。示例配置 `PIPELINE_SKIP_BURN=1` 默认跳过硬压；已有 `.env` 不会被覆盖。
5. `--project-dir` 只决定配置位置；下载项目和默认 batch 报告写入执行命令时的目录。
6. `*_MODEL` 非空时覆盖 provider 默认模型；需使用 `providers.json` 的 `default_model` 时清空对应值。更换 embedding 模型时使用独立向量库目录。

WhisperX JSON、词级对轴、glossary 常驻规则和字幕输出格式保持既有契约。多 ASR provider 属于后续版本设计，本版未实现。

详细迁移步骤见 [MIGRATION.md](../../MIGRATION.md)。
