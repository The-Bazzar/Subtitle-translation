# v2.0.1

修复下载阶段的 cookies 路径与 yt-dlp 缓存行为。

## 修复内容

- download、pipeline 和 batch 统一从命令启动时的执行目录读取 `cookies.txt`，不再回退到安装目录或 `--project-dir` 配置根。
- 获取视频标题与下载或刷新元数据使用同一 cookies 文件。
- 每次 yt-dlp 标题查询、下载或元数据刷新前，先使用同一 executable 和执行目录运行 `yt-dlp --rm-cache-dir`。
- 缓存清理失败时停止当前下载阶段，并保留 yt-dlp 的退出码和命令诊断。
- 增加新下载、已有原片、cookies 缺失、路径含空格以及清理和下载失败的回归测试。

## 升级须知

将 `cookies.txt` 放在实际执行 `subtitle-translation` 命令的目录。`--project-dir` 仍用于 `.env`、provider 和 template，不再决定 cookies 位置。

本版本不改变媒体输出目录、batch 资源调度、ASR recovery、字幕数据格式或翻译缓存。

详细行为与迁移说明见 [MIGRATION.md](../../MIGRATION.md)。
