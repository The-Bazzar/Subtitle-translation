# v2.1.0：原生 MFA 与联合双语翻译

## 主要变化

- 引入翻译后窗口 corpus MFA：共享模型完成一次 align/批量导出，支持合并来源窗口、分层缓存和整句粗时间回退。
- Windows x86_64 支持原生独立 MFA 环境，Linux x86_64 本机及显式 WSL 保留；修复 VAD 本地加载、用户 Python 包干扰和 SQLite 长路径问题。
- translate 单回合完成整句翻译与双语语义断句，移除独立 split 和硬性长度/拼接要求；无效分割保留整句原文及实际译文。
- glossary/source_review 处理翻译前源文编辑；proofreading 仅校对译文，不修改源文、事件或时间。
- 删除时间轴吸附、美化及相关参数，只保留独立场景检测。
- 新增 help 汇总所有子命令帮助；开关、模型与调优配置统一 .env，保留项目参数及 --only-*。
- Loguru 日志包含时间、级别、项目、阶段和每条 event 的完整双语内容；正常事件为 INFO，异常状态为 WARNING。
- 清理退役代码与测试、归档旧设计，修复 ASS/SRT 时间进位，并完善源码包的测试和文档内容。

## 升级注意

- 模板默认 MFA_ENABLED=1、PROOFREAD=0、PIPELINE_SKIP_BURN=1；已有 .env 不覆盖。缺失键由 setup 补齐。
- 首次安装：Windows 使用 scripts/setup.ps1 -InstallMfa，Linux 使用 scripts/setup.sh --mfa；已有项目可单独运行 subtitle-translation setup-mfa。
- MFA 当前仅支持英文源文。其他语言设置 MFA_ENABLED=0，继续使用 WhisperX 原生词轴；多 ASR Provider 留待后续版本。
- 删除 --mfa、--proofread、--quiet、--skip-*、--batch-size 等旧 CLI 参数，未知参数直接报错。QUIET 配置删除，控制台与文件统一由 LOG_LEVEL 过滤。
- 控制台固定 ANSI 配色，文件保持纯文本。单项目日志位于视频目录 subtitle-translation.log；batch 集中于执行目录 batch-result.log，每轮覆盖，不生成多份日志。
- 不需要删除媒体、识别 JSON、术语或翻译检查点；原 batch generation、锁、资源调度和原子发布边界保留。

## 验证

- Python 全量回归、PowerShell/bash 语法、diff 检查。
- wheel/sdist 内容与独立安装检查。
- Windows 原生环境的模型/VAD 加载、带空格路径及 corpus 导出/缓存复跑验证；不代表所有口音、语言或平台的声学质量保证。
