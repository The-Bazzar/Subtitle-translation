# v2.1.2：长视频上下文管理

本版本重新发布，替换原 v2.1.2 的 wheel 和源码包。已安装原包时，需要重新下载并强制重装；仅检查版本号无法区分两次构建。

- 文本 LLM 阶段在请求前检查上下文预算，接近模型窗口的 80% 时压缩可移除的历史，保留完整术语库、当前请求和活动工具调用链。不增加摘要模型调用。
- 优先读取本地 providers.json 的 model_info；缺失时只查询 OpenRouter 公开目录，不再请求各 provider 的 /models 或 Gemini 元数据接口。匹配忽略 vendor 前缀，但保留模型版本与变体；有冲突则不采用。
- 只为实际调用成功的模型回填窗口，按完整请求 ID 写入对应 provider 的 model_info；包括实际完成的 embedding 请求。仅检查预算或复用检查点时不写回，不扫描配置清单。已有有效窗口可继续读取；OpenRouter 窗口是标称值，未知模型的 32768-token 规划预算不写入。
- 联合翻译默认每批 20 个句段，独立校对留空时默认 10 个 event；已有 .env 显式值保持不变。原始字幕、时间轴和 batch 资源调度契约不变。

升级前手填过窗口的，可在 providers.json 的对应 provider 下维护 model_info；新建配置有示例。若当前请求本身就超过窗口，压缩不会截断正文。详见[迁移说明](../../MIGRATION.md)。

验证：本地全量测试 514 项，510 通过、4 跳过；网络、LLM 和媒体工具使用 mock。
