# v2.1.2：长视频上下文管理

- 文本 LLM 阶段在请求前检查上下文预算，接近模型窗口的 80% 时压缩可移除的历史，保留完整术语库、当前请求和活动工具调用链。不增加摘要模型调用。
- 优先读取当前 provider 的模型元数据；缺失时查询 OpenRouter 公开目录。公开目录忽略 vendor 前缀，精确比对模型名、版本与变体；有冲突则不采用。
- 首次查到的有效窗口会写入本地 providers.json 的 model_info，后续直接读取。手填窗口优先，未知回退值不写入；公开目录窗口仍是标称值。端点和密钥仍须自备。
- 联合翻译默认每批 20 个句段，独立校对留空时默认 10 个 event；已有 .env 显式值保持不变。原始字幕、时间轴和 batch 资源调度契约不变。

升级前手填过窗口的，可在 providers.json 的对应 provider 下维护 model_info；新建配置有示例。若当前请求本身就超过窗口，压缩不会截断正文。详见[迁移说明](../../MIGRATION.md)。

验证：本地全量测试 519 项，515 通过、4 跳过；网络、LLM 和媒体工具使用 mock。
