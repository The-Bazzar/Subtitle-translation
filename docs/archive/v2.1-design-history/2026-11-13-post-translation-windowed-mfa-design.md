# 翻译后窗口化 MFA 对轴与合并窗口设计

> 历史设计归档，不作为当前运行说明；当前规范见 docs/v2.1-architecture.md。

状态：2026-11-13 目标设计；首版已接入显式 --mfa，窗口 padding、吞吐和完整质量基准仍待扩展/验收。实际初值及验证范围见[实施说明](2026-11-13-windowed-mfa-implementation.md)。优先单一 WhisperX、en -> zh，多引擎和多语言入口保留。

语义阶段更新：独立源文 split 已并入 translate，同回合返回成对源/目标片段；本文后续关于预填英文事件、边界 ID、72 字符或严格译文拼接的早期描述由[联合双语语义协议](../../superpowers/specs/2026-11-13-semantic-bilingual-translation.md)取代。窗口定位/合并、sample 偏移和批量 MFA 约束不变。

本文替代旧目标中“glossary -> 全文 MFA -> beautify -> 依赖词轴的源文断句 -> translate”的顺序、窗口及缓存契约；安装 profile、资源 admission、原始 ASR/batch generation 和文件发布协议不变。当前实现以 AGENTS.md 与代码为准，旧集成文档保留早期路径记录，不能用于判断当前阶段顺序。

## 1. 目标流程

```text
ASR：听录文字、来源和句段粗时间；不要求原生词轴
-> glossary / source_review：术语、文本优选与字幕编辑，确定实际源文
-> 独立 LLM 源文断句：只选择文字边界，生成无精确时间的事件规划
-> translate：单回合整句翻译及固定事件译文分配
   -> 仅拼接不一致：保留完整源句及本次整句译文，回退为一个事件
-> MFA：以 ASR 粗时间定位/合并音频窗口，为最终事件对轴
-> beautify：对已验收的时间边界微调，不清空或重建事件文字/ID/译文
-> 可选纯译文 proofread -> ASS -> 可选 burn
```

MFA 接管原后置 proofreading 所在位置的时间处理职责，不承担译文校对。是否移除纯译文校对是独立事项；保留既有开关，`--no-proofread` 不等于跳过 MFA。只在最后一个时间阶段之后做显示时长/阅读速度检查，不用假时间驱动翻译。

## 2. 文本规划与翻译

glossary 定稿后源文只读。翻译句段从完整采用稿及来源映射组织，可用 pySBD 保留字符范围重建上下文，不复刻 ASR 硬分段。独立 LLM split 只输入完整源句、邻接上下文、文字合法边界 ID、语言/长度约束，不输入 ASR 词时间，不以缺少词轴为由跳过语义断句。

边界绑定定稿 hash、语言和规划版本。本地检查覆盖、顺序、唯一性、字符范围及词/固定表达不可拆约束，从定稿原样切出 `split_events.en`。恢复切片间空白后必须逐字符还原定稿，不允许丢词、改词、重复或以 token 相同掩盖标点变化。LLM 不生成时间戳，本地也不平均分配时间。

对轴前用独立文本事件产物保存 ID、segment-local `source_range`、源文、译文和 `timing_status=pending`；精确 `start/end` 缺省，不用 0 或 ASR 粗时间冒充精确事件时间。全稿位置另由 segment 全局范围/来源映射保存。该产物不能交给当前要求完整时间的 legacy loader、ASS 导出或 burn；ASR 粗范围单独作为音频定位资料。

translate 仍携带整句和全部源文事件，一回合输出整句译文与事件译文，不新增独立译文 split 请求，不改为已讨论但未实施的另一种响应 schema。事件 ID/文字固定，精确时间尚不存在。结构、ID 和非空检查通过但拼接不一致时，立即保留完整源句和整句译文，改用单一整句事件，原因只输出日志，不写原因字段或新增人工标记。后续 MFA 读取这个最终有效事件集合，不对已废弃的子事件先行对轴。

## 3. ASR 粗时间窗口

### 3.1 基础窗口

默认以对应 ASR 句段的粗起止时间定位音频，同时保留原始来源 ID、音频 generation、时间坐标与采用稿字符映射。粗时间只限定搜索区域，不是最终字幕边界，不要求 ASR 提供词轴，也不赋予某 Provider 真值地位。

对齐输入是“窗口音频 + 该范围完整定稿源文”，不是修订前原文、中文译文或孤立字幕碎片。一个窗口可以承载多个完整语句及多个事件，不能把每个短事件机械地变成一次 MFA 调用。规范音频提取保持与来源粗时间相同的时间原点/时间基准，不能直接混用剪辑前后的时间坐标。

缺少有效粗时间或可靠文字来源映射的范围暂不自动对轴，保留已有实际双语内容交人工；不暗中恢复整片音频加全文的无锚点路径。多语言/其他 Provider 后续必须声明并验证粗时间及坐标能力。

### 3.2 合并窗口

ASR 的一段不等于语义上的整句，允许合并同一项目、同一音频 generation 和时间基准中的相邻 ASR 窗口：

- 定稿完整语句或已选事件跨越多个 ASR 段时，合并覆盖其全部来源的连续窗口。
- 相邻处理单元共享同一 ASR 源段或必需上下文，无法独立形成完整音频/文字对应时，协调成一个处理块，避免只拿半句文字对齐整段音频。
- 合并范围取所需来源起点的最小值与终点的最大值，按文字顺序带齐范围内的定稿内容；不能只扩大音频而遗漏中间文字。
- 合并是处理粒度调整，不合并字幕文字事件、不重切中文、不修改 glossary 定稿，不跨项目/媒体代际，也不因 padding 重叠就合并所有窗口。

示意：ASR A 为 12–18 秒、B 为 18–24 秒；定稿语句横跨 A/B，则核心窗口为 12–24 秒，携带对应完整定稿及其全部事件。这里的数值只是示例，不是实现默认阈值。

窗口须有版本化的最大跨度、扩展次数及预算约束，具体数值在实现/样本验收时确定，不新增零散环境变量。因一个超长句或连续跨界依赖超过上限时，该范围降级，不能无界合并到全片，也不能为满足上限按字数强切或比例分配文本/时间。失败不移动后续窗口的来源锚点。

### 3.3 上下文余量与结果归属

核心窗口之外可增加有界前后余量，并裁剪到媒体有效范围。若纳入相邻语音作为对齐上下文，必须同时提供可确定的相邻定稿文字，显式区分上下文范围和本块负责发布的核心字符范围。

每个源文字符/事件只有一个结果归属。重叠窗口的上下文词不得重复发布；按确定的字符范围和来源归属裁剪，不靠时间中点、模糊匹配或“取看起来更好的一份”消歧。无法确定归属则该范围不自动通过。

## 4. MFA 对轴与验收

MFA 仍是唯一正式对齐器。直接对预定位的窗口/处理块及其定稿文字运行锁定 profile，不再依赖全片 `mfa segment` 消耗全文来建立文字位置。窗口内的进一步准备也必须维持锚点、文字覆盖和处理上限；不能用 VAD 区间按时长或字数比例分配全文。

工具环境通过 praatio 读取原生输出，规范化词与定稿建立可验证映射。对齐后按事件源文字符边界取首尾词时间，再加回规范音频裁剪的准确 sample 偏移一次，形成全局事件时间。不读取 ASR 词轴，不重新选择语义断点，不对中文音频强制对齐。

验收至少覆盖：

- 定稿文字覆盖、必要词完整、有限合法时间、顺序、窗口局部范围与全局偏移。
- 窗口与来源粗时间包络及获准扩展范围相容；合法单调时间不等于位置正确。
- 异常长词间空洞、语句跨度、处理块间重复/逆序和跨窗口归属。
- 一对多/多对一映射不可拆；预选事件边界落入无法分离的时间单元时不得平均插值。

具体异常阈值需版本化并用语料校准，不把诊断指标当作听录真实性评分。本方案不增加自动音频复核，不声称来源粗时间、MFA 成功或结构校验能证明说话内容正确。

## 5. 失败与后处理

失败只能影响相应来源窗口/语句，不继续推进全文文字游标或污染后续窗口。保留已采用源文和已有整句译文；无法为子事件定位时，将受影响完整语句投影为单一粗时间事件，使用来源 ASR 的包络，不用漂移的 MFA 准备区间、不回退修订前文字、不补造词轴。

这只是对轴/导出产物的降级投影，不修改不可变文本规划或重新请求翻译。没有可用粗时间时不伪造可正常导出的时间；该范围保留内容并交人工定位。诊断在日志明确显示，不依赖人工阅读工作 JSON。

beautify 只对已验收的 MFA 时间做有界微调，保持事件 ID、源文范围和双语内容不变；不能沿用当前清空 `split_events` 的前置 beautify 行为。粗时间事件不自动场景吸附，不为消除重叠重排内容或拉伸词轴。可选纯译文校对只改目标文字，不改时间，不触发重对轴。

## 6. 缓存、资源与迁移

- 文本规划身份绑定采用稿、上下文、语言、长度/边界策略和 split 模型/prompt，不绑定 ASR/MFA 词时间或场景数据。
- 翻译身份绑定有效文本事件、完整语义上下文、术语/检索、模型/prompt、语言和拼接策略，不绑定精确事件时间。
- 原生 MFA 词轴身份绑定规范音频/裁剪坐标、粗时间来源、合并/余量策略、实际块内文字及上下文、模型/词典/profile、环境与自适应 corpus。事件时间投影另绑定最终有效事件规划和映射策略。
- 当前全部有效窗口以独立音频/文字加入同一个项目 corpus，一次 align、一次批量导出，避免每个窗口重复模型初始化；不连接成一条无锚点全文音频。共享自适应意味着缓存绑定整个 corpus，不能混用旧单窗口结果，详见[批量执行契约](../../superpowers/specs/2026-11-13-windowed-mfa-corpus-batching.md)。
- 只有事件边界/译文变化而块内源文和音频不变时，优先复用已验证词轴并重做投影；若有效事件变化导致窗口合并、文本或 corpus 改变，则对相应依赖重算，不能承诺无条件复用 MFA。
- 只改变 MFA/窗口/beautify 配置时不重发有效翻译；不能让后置时间 hash 反过来成为文本规划或翻译的输入，避免循环缓存依赖。
- 采用新的顺序/窗口/坐标和规划策略身份。旧全文对齐缓存、旧依赖词轴的事件规划不能只因文字相同而命中新路径。保留原始候选与已有文件，不批量删除用户产物；跨协议翻译复用须另经完整身份/覆盖检查。
- batch 顺序变为 recognize -> glossary -> text split -> translate -> windowed MFA -> timed postprocess；沿用现有 postprocess CPU/IO admission，MFA 固定 `num_jobs=1`，不为每个窗口创建新并行池。
- preflight 仍在任务开始前检查 MFA runtime/媒体，不等到付费翻译完成后才发现依赖缺失。取消优先于回退，原始 `.asr.json`、锁、媒体/对齐 generation、candidate 和原子发布语义不改。

## 7. 实施与验收

先分离文本规划和定时数据模型，再接入窗口规划/合并及偏移映射，随后迁移 MFA/beautify 的顺序和缓存，最后适配 standalone/batch 与导出。保留当前默认路径和实验开关，未验收前不宣称新路径可用；多引擎继续暂缓。

确定性测试必须覆盖无 ASR words 的正常 split/translate、跨 ASR 段合并、完整上下文、窗口上限与防级联合并、重叠归属、坐标原点和偏移仅加一次、跨不可拆词组、MFA 失败不串扰后续窗口、翻译整句回退后只对最终事件定时、beautify 保留双语事件、缓存分层失效、取消和单一资源 admission。单元测试 mock 外部依赖，真实音频基准独立执行。

真实基准需对照来源粗时间及人工抽样边界，报告跨窗口/后半段漂移、局部失败、边界误差、过长/过快字幕和人工量；不能只凭文字覆盖及时间单调性宣布对轴成功。

本变更涉及 D1/D2/D3/D6/D7 的数据、阶段顺序、缓存、协议与职责，需要实现 PR 评审。本文不修改安装版本、provider prompt example 文案或当前用户媒体/字幕。
